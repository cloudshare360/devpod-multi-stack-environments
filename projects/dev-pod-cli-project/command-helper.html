DevPod Interactive Command Helper

Copy and execute DevPod commands with ease

🛠️ Installation Commands

Download DevPod
Downloads the latest DevPod binary for Linux
curl -L -o devpod "https://github.com/loft-sh/devpod/releases/latest/download/devpod-linux-amd64"
Install DevPod
Installs DevPod to the system PATH
sudo install -c -m 0755 devpod /usr/local/bin
Verify Installation
Checks if DevPod was installed correctly
devpod version

🚀 Quick Start Commands

List Workspaces
Shows all existing DevPod workspaces
devpod list
Create Workspace
Creates a new workspace from the current directory
devpod up --id my-workspace .
Open in VS Code Desktop
Opens the workspace in VS Code desktop application
devpod ide vscode my-workspace
Open in VS Code Browser
Opens the workspace in VS Code browser (no desktop installation needed)
devpod ide openvscode my-workspace

🔧 Workspace Management

Check Status
Shows the current status of a workspace
devpod status my-workspace
SSH Access
Opens an SSH connection to the workspace
devpod ssh my-workspace
Stop Workspace
Stops a running workspace
devpod stop my-workspace
Delete Workspace
Permanently deletes a workspace
devpod delete my-workspace

🐛 Troubleshooting

Check Docker
Verifies Docker installation and connection
docker version
View Logs
Shows workspace logs for debugging
devpod logs my-workspace
System Cleanup
Cleans up unused Docker resources
docker system prune -f
